Nacre — version portable

Décompressez tout le ZIP dans un dossier accessible en écriture, puis lancez « Nacre Portable.cmd ».
Le profil (réglages, favoris et listes personnalisées) est stocké dans le dossier NacreData, à côté de Nacre.exe.
Le dossier peut être déplacé ou copié avec son profil. Ne lancez pas cette version depuis un dossier en lecture seule.
Cette version n'installe pas de raccourci Windows.
