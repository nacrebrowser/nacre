VERIFICATION TOOLS

Test the connection

These third-party sites run their own tests and may receive your IP address, browser information and requests needed for testing. Nacre does not receive their results. Open them only if you agree to these requests.

1 · Confirm Tor

Activate Tor in Nacre then open the official test. It should indicate that the browser is using Tor. Also check the country presented by the geolocation site if it is important for your use.

Open check.torproject.org ↗

2 · Examine IP, DNS and WebRTC

With Tor active, consult the IP, DNS and WebRTC tests. Compare with Tor disabled. A geolocation result can be imprecise and a spot test does not prove the absence of any leaks.

IP ↗DNS ↗WebRTC ↗

3 · Understanding the browser fingerprint

This test estimates how distinctive the browser characteristics visible to a site are. Nacre does not claim to make its fingerprint anonymous or identical to Tor Browser’s.

Open Cover Your Tracks from the EFF ↗

4 · Check the shutdown of Tor

  1. Connect Tor in Nacre and open an HTTPS page.
  2. In Windows Task Manager, end the process tor.exe.
  3. The Nacre page immediately displays that Tor is stopped and offers the “Reconnect Tor” button; sessions remain forced to a closed local port.
  4. Verify that Nacre displays its own page instead of the site's offline message. No direct connection should be attempted. After reconnecting, Nacre should return to the requested page.
  5. Relaunch Tor from Nacre before continuing.

This test is manual and must be redone after any modification of the proxy. The expected behavior comes from the local proxy being kept without egress service; This page cannot certify your Windows network configuration.

External tests do not replace independent analysis of code and network traffic.
